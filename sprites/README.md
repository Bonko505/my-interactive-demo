# Спрайти: стоїть, крокує, біжить (p5.js)

**Демо:** https://bonko505.github.io/my-interactive-demo/sprites/

Скетч показує персонажа з чотирма анімаціями з одного спрайтшіта: стоїть (4 кадри, 4 FPS), крокує (6 кадрів, 11 FPS), біжить (6 кадрів, 15 FPS) і стрибає (4 кадри за 0,5 с). Аркуш має формат PNG із прозорістю, розмір 192×128 px, кадр 32×32 px, по одному рядку на анімацію; для Варіанта B це власний піксель-арт `hero.png`, завантажений у `preload()`, а для Варіанта А такий самий аркуш малюється в коді через `createGraphics()`. Кадри вирізаються 9-аргументним `image()`, а швидкість анімації рахується через `deltaTime`, тому однакова на екранах 60 і 144 Гц; `noSmooth()` залишає пікселі чіткими при збільшенні. Керування: 1/2/3 — стояти/крокувати/бігти, пробіл — стрибок, стрілки — рух, F або кнопка Flip — дзеркало, слайдер або −/+ — масштаб, S — джерело (код/PNG), H — показати hitbox. Hitbox — прямокутник, менший за кадр (тіло без хвоста й вух), окремий для кожної анімації, і він використовується для збирання монет. Покращити можна плавні переходи між анімаціями, гравітацію та платформи замість вигляду згори, а також керування дотиком на телефоні.
